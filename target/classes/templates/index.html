вставьте сюда URL страницы и нажмите кнопку "сканировать"
1. В окно, на которое смотрит носорог, вставьте ссылку на страницу книги, из текста которой
вы хотите создать учебный материал. Интересные книги можно найти вот здесь

2. Нажмите кнопку "сканировать". Когда скан страницы загрузится, нажмите "распознать"
для распознания отсканированного текста. Это может занять несколько минут.

3. Нажмите кнопку "создать урок". Текст будет разделен на фрагменты, содержащие
примерно по тридцать новых слов. Каждый фрагмент будет сопровожден кратким
словариком из тридцати - тридцати пяти новых слов с переводом.
